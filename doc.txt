PROJECT NOTES
=============

Secrets are NOT stored in this file anymore.
All credentials (Django SECRET_KEY, Printify API token, Stripe keys,
email password, n8n shared secret) live in the untracked `.env` file.
See `.env.example` for the list of required variables.

If you need to rotate the Printify token, update PRINTIFY_API_TOKEN in `.env`.
